# Contributing

Thanks for your interest in contributing to `xtb2sure`.

## Setup

1. Install Node.js 24+.
2. Install dependencies:

```bash
npm install
```

## Validate changes

Run the test suite before opening a pull request:

```bash
npm test
```

## Guidelines

- Keep behavior deterministic and fixture-driven.
- Add tests for every functional change.
- Prefer small, focused pull requests.
